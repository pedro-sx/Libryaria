# Libryari.dev

Biblioteca digital minimalista da Verset.dev.

## MVP atual
- Home editorial responsiva
- Estantes automáticas por categoria
- Importação de PDF/EPUB/MOBI/AZW/AZW3 (protótipo visual)
- Modal de importação
- Filtros de biblioteca (UI)
- Base visual preparada para leitor e API
